Escenario de prueba : Consulta de disponibilidad horaria por cuadros de 1 hora en Calendario Detallado.
Pasos de la prueba :
1. En la vista '/horarios', el usuario hace clic sobre una tarjeta de día (ej. Lunes o Sábado).
2. El usuario observa la sección 'Calendario Detallado' que se actualiza para el día seleccionado.
3. El usuario cuenta y examina los cuadros de horas individuales generados entre la hora de apertura y cierre.
4. El usuario verifica que cada cuadro muestre:
   - El rango de 1 hora (ej. '08:00 - 09:00', '19:00 - 20:00').
   - El estado 'Disponible' con color verde si no tiene reservas o bloqueos.
   - El estado 'No disponible' con color rojo si coincide con una reserva o bloqueo.
5. El usuario comprueba que no se revele información privada de clientes.

Requisitos previos : Base de datos con horarios y reservas de prueba.
Navegador : Chrome en Windows.
Datos de prueba : Selección de días con reservas confirmadas y días con espacios libres.
Resultados esperados : La cuadrícula muestra exactamente un cuadro por cada bloque de 1 hora con su hora inicio-fin, estado claro y color representativo según disponibilidad.
Resultados reales : Como se esperaba.

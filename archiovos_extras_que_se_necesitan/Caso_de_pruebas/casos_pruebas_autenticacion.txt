CASO DE PRUEBA: #CP-AUTH-001
================================================================================
ID del caso de prueba : #CP-AUTH-001
Escenario de prueba : Inicio de sesión exitoso con rol de Administrador.
Pasos de la prueba :
1. El usuario navega a la página principal del sistema (/).
2. El usuario hace clic en el botón 'Iniciar Sesión' del encabezado.
3. El usuario ingresa el correo electrónico 'admin@cancha.com' en el campo 'Email'.
4. El usuario ingresa la contraseña 'admin123' en el campo 'Contraseña'.
5. El usuario hace clic en el botón 'Ingresar' / 'Iniciar Sesión'.

Requisitos previos : Usuario con rol 'admin' registrado y activo en la base de datos.
Navegador : Chrome en Windows.
Datos de prueba : Correo: admin@cancha.com | Clave: admin123
Resultados esperados : El sistema autentica las credenciales y redirige exitosamente a la vista '/admin/dashboard' mostrando las opciones del panel de administración.
Resultados reales : Como se esperaba.
Estado de la prueba: Aprobado/Reprobado : Aprobado
